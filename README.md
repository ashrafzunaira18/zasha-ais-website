## 📁 Project Architecture & Files

- **`index.html`**
  The main corporate landing page built with the Inter typography and corporate teal/orange design system:
  1. **Home (Hero)** with factory backdrop and CTA to book inspections.
  2. **About** with verbatim company copy reflowed for web + Vision and Mission cards.
  3. **Value Props**: *"Your Standards, Our Precision"* + cards 01 Precision, 02 Assurance, 03 Dependability.
  4. **Reporting Process**: 4-point workflow (*Effective Communication, Data-Driven Decision Support, Performance Optimization, Empowering Client Control*).
  5. **Our Services**: Full catalogue of all 21 inspection services with photo slots and 1-click booking triggers.
  6. **Gallery**: 8-photo grid of factory floor operations, fabric rolls, stitching lines, and container stuffing.
  7. **Sample Reports**: 3 report cards with interactive preview modal and PDF/WhatsApp request.
  8. **Coverage in Pakistan**: Heading and city tags for Sialkot, Lahore, Faisalabad, Multan, Karachi, Islamabad.
  9. **Contact Us / Footer**: Condensed About blurb, Our Services quick list, direct email, phone, social links, and contact form.

- **`login.html`**
  Dedicated authentication page:
  - Split-screen corporate layout with industrial assurances on the left.
  - **Sign In** tab (Work Email & Password).
  - **Create Account (Sign Up)** tab (Company, Name, Role, Email, Phone, Password).
  - **1-Click Demo Buyer Sign In** button for instant evaluation without typing credentials.

- **`portal.html`**
  Dedicated client inspection dashboard (open directly on the page, no pop-up/modal):
  - **Tab 1: Book New Inspection**: Complete 9-stage inspection booking dossier form, pre-filled client profile, and Section 8 confirmation card with 1-click WhatsApp dispatch and printable booking slip.
  - **Tab 2: My Bookings**: Table tracking submitted bookings with live status tags and WhatsApp tracking links.
  - **Tab 3: Fee Estimator**: Interactive quantity slider with instant fee ($199 flat rate), man-days, and AQL sample units.

## 💻 How to Run Locally

### Option 1: Direct File Explorer Open
Double-click `index.html` in your file explorer to open it in any web browser.

### Option 2: Local Web Server
```bash
# Using npx
npx serve .

# Or using npm if dependencies installed
npm start
```
Then visit `http://localhost:3000` in your browser.
